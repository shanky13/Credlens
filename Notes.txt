def base_probability(user_band, card_band):
    diff = ord(user_band[-1]) - ord(card_band[-1])

# STEP 6 — Card Risk Adjustment (Issuer Selectivity)

```python
def card_risk_adjustment(card):
    if card["Is_Secured"] == "Yes":
        return 0.20

    tier = card["Card_Risk_Tier"]
    if tier == "ENTRY":
        return 0.10
    elif tier == "MAINSTREAM":
        return 0.0
    elif tier == "PREMIUM":
        return -0.05
    else:  # SUPER_PREMIUM
        return -0.10
```

This reflects **real issuer behaviour**.

# STEP 7 — Final Probability Assembly

```python
def compute_approval_probability(user, card):
    base = base_probability(user["score_band"], card["Eligible_Score_Band"])
    income_adj = income_adjustment(user["salary"] / card["Min_Income"])
    risk_adj = card_risk_adjustment(card)

    prob = base + income_adj + risk_adj

    # Clamp safely
    prob = max(0.05, min(prob, 0.90))

    return round(prob * 100)
```

This function should:

* Live **outside Streamlit**
* Be testable
* Be deterministic
